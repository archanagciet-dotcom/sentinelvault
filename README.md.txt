# Sentinel Vault

## Project Description

Sentinel Vault is a Secure File Storage and Sharing System developed using Spring Boot, React, JWT Authentication, Spring Security, and MySQL. It allows users to securely upload, preview, download, delete, and share files while maintaining audit logs for every action.

---

## Features

- User Registration
- User Login
- JWT Authentication
- Secure File Upload
- File Preview
- File Download
- File Delete
- File Sharing
- Dashboard
- Audit Logs
- User Profile
- Change Password
- Admin Module
